## Per-service notes (auth, retries, validation — the B9.9 checklist where it applies)

- **Stripe.** Auth = secret key + webhook HMAC secret (env). The webhook verifier implements Stripe's `t,v1` scheme with a 300s tolerance and `timingSafeEqual` (`lib/stripe.js:103-131`) — real code, but hand-rolled rather than the official SDK (`stripe.js:99-102` recommends `constructEvent` for edge cases). No retry/backoff needed (inbound). **Idempotency gap:** `invoice.payment_succeeded` → `issueCredits` has no redelivery dedupe (DAT-009); the purchase branch is guarded (`server.js:775-780`). Event types handled: `checkout.session.completed`, `customer.subscription.created/deleted`, `invoice.payment_succeeded` (`server.js:771-807`).
- **Bunny.** Auth = API key + storage zone + pull-zone hostname (env). Pull-zone model: player loads from edge; origin redirects (302, `cdn.js:106-111`). No retries needed client-side (CDN's job). Upload-to-storage-zone at import time is explicitly not wired (`cdn.js:89-93`).
- **Privy.** Auth = App ID (public) + dashboard allow-listing. No token refresh logic in-repo (SDK-managed). Degradation is honest (warn + passthrough).
- **IPFS/Arweave (storage module).** Auth: none for Kubo API (assumes local/trusted node); Arweave via wallet JWK signing. Timeouts on every request (`ipfs.js:37-47`, `arweave.js:61-71`). Unwired — the checklist items (pinning persistence, gateway fallback) are documented in `PINNING.md`/`LIMITATIONS.md` but not exercised by any live path.
- **Vimeo.** No auth, no API, no retries — it's a textarea. Validation = email regex per row + per-film dedupe (`server.js:515-530`); invalid rows are reported back, not dropped silently (`server.js:542`). Failure modes traced in `notes/flows/vimeo-import.md`.
- **Cloudflare Worker.** Auth (real path) = Privy JWT in `Authorization` header; demo tokens accepted in simulation (`access-control.js:61,90`). R2 vars (`R2_BUCKET_NAME`, `R2_ACCOUNT_ID` in `.env.example:42-43`) are documented but unread by any deployed code — BLD-007 owns that ledger entry.
- **Indexer.** No auth (public GraphQL). No pagination beyond `first: 100/500/1000` caps; no retry; all errors swallowed → `null` → fallback. No staleness signal (30s in-memory cache, `indexer.ts:14-36`).

## What's missing before any of this goes live (DAT view)

1. Stripe: keys + webhook idempotency (DAT-009) + counsel sign-off (bannered, not done).
2. Bunny: env + pull zone + import-time upload wiring.
3. Chain: contract deploy (all `0x0`), then the on-chain↔off-chain reconciliation design (DAT-008) — without it, paying on-chain buys nothing streamable.
4. Arweave wallet handling: full JWK in env is the documented path (`.env.example`) — needs a secrets-management story before real use.
