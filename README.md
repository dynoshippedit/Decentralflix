# Decentralflix

Decentralized film distribution \u2014 a movie ticket as an NFT. Creators get paid directly, no middlemen.

## The idea

- Viewers buy movie tickets as NFTs
- Each purchase splits automatically on-chain: **75% to the creator, 25% to the platform**
- Non-custodial: funds go straight to wallets, no middleman holding them

## Status

In active development. Smart contracts are **unaudited** \u2014 do not use with real funds.
